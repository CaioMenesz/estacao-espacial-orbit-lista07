# Missão: Estação Espacial Orbit

Projeto da lista 07 da disciplina de Gestão da Qualidade de Software (GQS), focado na simulação de um sistema de suporte de vida para uma estação espacial.

## Camadas do ambiente

- develop: ambiente de desenvolvimento, onde as novas funcionalidades e correções são implementadas e testadas inicialmente.
- stage: ambiente de homologação, utilizado para validar a integração e o comportamento do sistema antes da entrega.
- main: ambiente de produção, contendo a versão estável e pronta para uso.
